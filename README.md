# 🖼️🧪 Canvas Lab Pro

**HTML5 Canvas project with a Vite development entry, responsive canvas sizing, a minimal animation engine, and checked-in bundled assets.**

🏷️ Maintained in [qamotech/CanvasLab](https://github.com/qamotech/CanvasLab) · 🌐 Public repository

## ✨ What is here

- 🖼️ Canvas element and browser UI shell.
- 📐 Canvas sizing on window resize.
- 🔁 requestAnimationFrame engine scaffold.
- 📦 Source files alongside compiled CSS/JavaScript assets.

## 🧭 Try the project

Start the development server, inspect the canvas shell, and use src/engine.js as the entry point for drawing experiments. Compare the bundled page with the source before editing.

## 🚀 Local setup

```sh
git clone https://github.com/qamotech/CanvasLab.git
cd CanvasLab
```

Use Node.js and npm compatible with the versions in `package.json`. Install dependencies locally, then launch the declared development command:

```sh
npm install
npm run dev
```

Open the address printed by the development server. The manifest is the source of truth for commands:

| Command | Declared operation |
|---|---|
| `npm run dev` | `vite` |

Install/build scripts can execute code. Inspect project configuration and keep secrets in local configuration excluded from Git. No dependency installation or application build was performed for this documentation update.

## ⚙️ Configuration & data

The inspected source engine clears the canvas each frame but does not draw a scene. Only a dev npm script exists; no build or test script is declared. Do not describe the source scaffold as a complete asset editor.

Keep credentials, private exports, customer records, and personal information out of commits and screenshots. A local browser demo is not evidence of account security, reliable persistence, or connected external services. Preserve exports before changing storage keys or resetting an application.
